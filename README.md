# Data Driven Testing Workspace

This repository contains two small Python projects:

- `Create Assignment/` — helper scripts and test data for assignment creation.
- `CreateAQuiz/` — quiz creation scripts organized in `level_1/` and `level_2/`.

To push this project to GitHub:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <git-repo-url>
git push -u origin main
```
